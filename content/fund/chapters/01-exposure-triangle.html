基礎

曝光三角:三個轉盤怎麼互相牽動

光圈、快門、ISO 做的是同一件事——決定有多少光線落在感光元件上——只是各自帶著一個「副作用」。搞懂這個副作用,你才能決定要犧牲哪一個。

先建立一個畫面 通用知識

把感光元件想成一個水桶,快門是水龍頭開多久,光圈是水管粗細,ISO 是水桶本身有沒有先「加水位刻度」讓它看起來裝比較滿。三者的組合最終只影響一件事:桶子裝到多滿(=曝光量)。同一個曝光量,可以用無數種光圈快門 ISO 組合達到——差別在於畫面除了亮暗之外還發生了什麼。

三個變因各自的「副作用」

變因控制曝光的方式順便決定的事
光圈(Aperture)光圈開越大(F 數字越小),進光越多景深深淺——背景模不模糊
快門(Shutter)快門開越久,進光越多動態怎麼被記錄——凝結還是拖出殘影
ISO(感光度)數值越高,同樣的光被放大得越亮雜訊多寡——畫面乾不乾淨

換句話說,曝光三角真正在問的問題不是「怎麼拍才夠亮」,而是「這張照片,我要用哪個副作用去換取正確的亮度」——要淺景深就先決定光圈,要凝結動作就先決定快門,兩者都不重要就先鎖 ISO 讓相機自己找剩下兩個的平衡。這個「先決定哪一個、讓相機或你自己填另外兩個」的思考順序,就是接下來三章要分別講的內容。

EV 與「一級」是什麼意思

攝影裡常聽到「加一級曝光」「差兩級」,「一級(1 stop)」的意思是曝光量剛好加倍或減半。光圈、快門、ISO 各自都有自己的一級:

變因「重一級」的變化方向常見數值序列(每格差一級)
光圈F 數字變小 = 光圈開大 = 多一級光F1.4 → F2 → F2.8 → F4 → F5.6 → F8 → F11 → F16
快門時間變長 = 多一級光1/1000 → 1/500 → 1/250 → 1/125 → 1/60 → 1/30 → 1/15
ISO數值變大 = 多一級光100 → 200 → 400 → 800 → 1600 → 3200 → 6400

這張表最重要的用途:任何一個變因少一級,只要另一個變因多一級,曝光量就打平。例如光圈從 F4 收到 F5.6(少一級光),把快門從 1/250 放慢到 1/125(多一級光),照片一樣亮——但景深變深了、動態模糊風險也增加了。這就是「換算」的全部原理,之後看到任何配方表在調整參數,都是在做這個換算。

為什麼相機常常幫你做這件事 本站建議

絕大多數相機的「光圈優先」「快門優先」模式,就是你鎖住其中一個變因(連同副作用一起鎖住),相機自動用另一個變因去打平曝光。這也是為什麼弄懂這張換算表之後,你會發現「先選模式」這件事其實就是「先決定我要哪個副作用」——選光圈優先,代表你在乎的是景深;選快門優先,代表你在乎的是動態怎麼被記錄。

互斥的取捨:沒有「三個都要」這回事

初學者最常卡住的地方,是想同時要「淺景深 + 凝結動作 + 乾淨無雜訊」——但光線是固定的,三個變因只要有兩個被鎖定在「好的方向」,第三個一定被推向「有代價的方向」。實務上的思考方式是排出優先順序:這張照片最重要的是哪一個?其餘兩個各讓一點步。

你最在乎先決定讓步的通常是
背景要糊,凸顯主體光圈開到最大或接近最大快門與 ISO 隨光線自動配合
畫面不能糊(小孩、寵物、運動)快門先鎖在安全值以上光圈開大、ISO 拉高去換
畫質要乾淨(風景、靜物、光線充足)ISO 鎖在低值光圈收小、快門放慢用腳架配合
練習
  1. 找一個光線穩定的場景(例如窗邊),用同一個曝光量,分別用「大光圈+快速快門+低ISO」「小光圈+慢快門+低ISO」「小光圈+快速快門+高ISO」拍三張,亮度應該接近,但背景模糊程度、有沒有手震、雜訊感會明顯不同。
  2. 對照上面「一級」的表,自己動手換算一次:光圈從 F2.8 收到 F4(少一級),快門要從幾分之一秒放慢到多少,曝光才會一樣?拍出來驗證你的換算對不對。
