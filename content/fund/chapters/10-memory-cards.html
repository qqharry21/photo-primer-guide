記憶卡怎麼選:規格看懂就好挑

卡殼上擠了一堆數字跟符號,其實只有幾組系統,各自量的是不同東西。看懂這幾個,不管換哪台相機都用得上。

先看懂卡殼上那些符號在講什麼

同一張卡的角落常常同時印著好幾種標示——這不是同一個規格重複寫,是好幾套不同的認證系統疊在同一張卡上,各自量測不同的東西。

四套系統,各自保證的「最低寫入速度」

系統卡上長相等級與對應速度白話意義
Speed Class數字外面一個圈2 / 4 / 6 / 10(MB/s)最早期的標準,現在幾乎所有卡都滿足 Class 10,參考意義已經不大
UHS Speed Class數字外面一個 U 形U1 = 10MB/s、U3 = 30MB/s給 UHS 匯流排規格的卡專用,U3 是現在拍片卡的常見門檻
Video Speed Class「V + 數字」V6/V10/V30/V60/V90(MB/s)專門為錄影設計,涵蓋範圍比 UHS Speed Class 更廣,拍片規格看這個最準
應用效能等級(A)「A + 數字」A1 / A2量的是隨機讀寫效能,跟手機/掌機跑 App 比較有關,對拍照錄影影響不大

通用知識 這幾套系統是不同時期由 SD 協會(SD Association)陸續追加的,不是新的取代舊的——所以才會同一張卡上疊著好幾種標示。拍片的話,認 Video Speed Class(V 開頭)最準,因為它就是專門為錄影而設計的門檻。

容量與格式:名字不一樣,能用的檔案系統也不一樣

類型容量範圍格式

通用知識 名稱不是行銷用詞,是實際的容量分級——買卡、認相機規格表時看到「支援 SDXC」,代表相機能吃 64GB 到 2TB 這個範圍。舊機器如果只寫「支援 SDHC」,插 128GB 以上的 SDXC 卡可能完全不認,不是卡壞了。

卡的物理尺寸是另一件事

SD、SDHC、SDXC⋯⋯講的是容量與格式;全尺寸 SD 卡跟 microSD 卡講的是物理大小,兩個維度互相獨立——市面上 microSDXC、SDXC 都存在,買之前先確認機身卡槽吃哪種尺寸,兩者不能直接互插(microSD 可以透過轉接卡變成全尺寸大小使用,反過來不行)。

匯流排介面:卡再快,介面跟不上也沒用

卡背面的金手指排列方式決定了它是 UHS-I 還是 UHS-II——UHS-II 卡會多一排額外的金手指,理論頻寬比 UHS-I 高出不少 通用知識。但這件事有個前提:相機的卡槽本身也要支援 UHS-II,才吃得到這個速度;插在只支援 UHS-I 的機身裡,UHS-II 卡只會以 UHS-I 的速度運作,多花的錢等於白花。買卡前先查清楚自己機身卡槽支援到哪一代。

依用途,你真正該看哪個數字

你主要拍什麼該看的最低門檻為什麼
單純拍照(JPEG/RAW),不太錄影U1 / V10 以上即可靜態照片對持續寫入速度的要求遠低於影片
連拍大量 RAW,在意緩衝區多快清空寫入速度越高越好連拍時相機要把資料從緩衝區持續寫進卡裡,寫入速度不夠,連拍張數會被限制或直接卡住
一般 4K 30/60fps 錄影至少 U3 / V30這是大多數 4K 規格影片實際會用到的資料流量門檻
高規格影片(6K、4K 120/240fps 高幀率)V60 以上更穩幀率、位元率越高,持續寫入的資料量越大,門檻卡在剛好會沒有餘裕
包裝上的「最高 XXX MB/s」通常是讀取速度,不是寫入速度

本站建議 錄影跟連拍吃的是寫入速度,包裝正面最顯眼的那個大數字常常是讀取速度(把素材匯出到電腦時才用得到)。真正決定「會不會錄到一半跳出中斷警告」的是 Speed Class / UHS Speed Class / Video Speed Class 這幾個等級標示,不是那個最大的數字。

買卡的實務眉角

怎麼避免踩雷

本站建議 高容量記憶卡是網路購物平台上假貨、標錯容量的重災區——一張賣得比同容量正品便宜一大截的卡,實測容量常常灌水(表面顯示 256GB,實際能寫入的只有幾十 GB,超過就開始覆蓋舊資料或直接壞軌)。跟信譽良好的通路或原廠授權賣家買,比單純比價更重要。

讀卡機的速度也要對得上卡的速度——用一個只支援 UHS-I 的讀卡機去讀 UHS-II 的卡,匯出素材一樣會被讀卡機卡住,速度回到 UHS-I 等級。

練習
  1. 拿出手邊的記憶卡,對照上面的圖跟表,找出卡殼上實際印了哪幾種符號、各自代表什麼等級。
  2. 查一下自己相機的規格表(或本站對應裝置分頁),確認機身要求的最低等級,跟手邊的卡對一下有沒有低於門檻。
  3. 記得永遠在相機裡格式化記憶卡,不要在電腦上格式化——不同機身可能用不同的資料夾結構寫入,在電腦格式化容易造成相機認不得卡或寫入異常。
