快拍 Snap:GR 的靈魂

不對焦就拍。這是 GR 之所以是 GR 的原因。

快拍在做什麼

一般拍照流程是:半按 → 相機找焦點 → 嗶一聲 → 全按 → 拍到。這中間有零點幾秒的延遲,街上的瞬間常常就過了。

快拍的做法是:你事先告訴相機「就對焦在 2.5 公尺」,按下去立刻拍,完全不等對焦。

官方定義:「在設定的距離鎖定焦點」說明書 p.58。

可以設哪些距離

MENU → A1 對焦設定 → 快拍對焦距離

八個選項:0.3m / 1m / 1.5m / 2m / 2.5m / 3.5m / 5m / ∞ 官方規格說明書 p.26

不進選單也能改距離

按住上鍵(微距)不放,同時旋轉前電子轉盤,就能直接更改快拍對焦距離 說明書 p.58。走在路上隨時可以切。

為什麼不對焦也會清楚?因為景深

起手式

本站建議 Av 模式 + F8 + 快拍對焦距離 2.5m。這組合能覆蓋大部分街頭距離。之後用相機的景深顯示自己微調成你的習慣值。

完全按下快拍:一台相機,兩種節奏

這是 GR 最迷人的功能。開啟之後 說明書 p.64:

你的手指相機的反應
半按快門正常自動對焦,慢慢拍
直接全按以快拍對焦距離立刻拍攝,零等待
MENU → A1 對焦設定 → 完全按下快拍 → 開啟

設為開啟時,拍攝畫面會顯示圖示與拍攝距離 p.64。

不是所有人都開它

查到的兩位 GR IV 使用者都把這個功能關掉,理由是容易誤觸、會拍到不想要的照片。兩種做法都合理。建議先開啟試兩週,如果常常誤觸就關掉。詳細比較見「別人怎麼設」那一章。

以下情況無法使用完全按下快拍
  • 快拍距離優先(Sn)模式
  • 影片模式
  • 微距模式
  • 「對焦」已設為手動對焦、快拍、∞ 時
  • 驅動模式設為自拍時

說明書 p.64

Sn 模式:GR IV 新增的快拍專用模式

模式轉盤上的 Sn = 快拍距離優先自動曝光 說明書 p.51。在這個模式下:

轉盤控制什麼
前電子轉盤快拍對焦距離
後電子轉盤(ADJ)景深(分 3 級選擇)
曝光補償曝光補償

官方說明:「M 模式下可調整快拍對焦距離與景深。對焦模式以快拍動作,景深可分 3 級選擇。」(此處 M 為說明書中代表快拍距離優先的符號)說明書 p.51

白話:你只管「對多遠」和「要多深」,光圈快門相機自己算。 這是為街拍設計的模式,新手其實非常好上手。

把快拍放到一顆按鍵上

不想每次進選單切換的話,可以指定給 Fn 鍵:

MENU → D2 操作自定義 → Fn 按鈕設定 → Fn 按鈕 → 切換快拍

之後按一下 Fn 就能在快拍與原本的對焦模式之間切換 說明書 p.59。同樣可指定的還有「切換手動對焦」「切換追蹤 AF」「快拍對焦距離」p.134。

快拍搭配曝光模式、連拍、握持習慣兜成一套完整的上街流程,見街拍實戰。

練習 09
  1. 設定:Av 模式、F8、快拍對焦距離 2.5m、完全按下快拍開啟。
  2. 出門拍一整天,完全不半按快門,一律直接全按。感受那個速度。
  3. 練習「按住上鍵 + 轉前轉盤」改距離,不看選單就能從 2.5m 切到 1m。
  4. 換到 Sn 模式,三種景深等級各拍一組比較。
