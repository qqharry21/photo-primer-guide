客製化:ADJ・Fn・USER

GR 最大的優勢是幾乎所有操作都能設成「不用進選單」。這章值得花一個晚上。

第一層:ADJ 模式(五個快速設定)

在拍攝模式下按下 ADJ / 後電子轉盤,就會進入 ADJ 模式,叫出五個你指定的功能 說明書 p.22。

怎麼用

  1. 拍攝模式下按下 ADJ 轉盤,顯示五個功能圖示。
  2. 用左右鍵選功能。
  3. 用上下鍵選數值。需要詳細設定就按 Fn。
  4. 按 OK 完成,回到可拍攝狀態。

說明書 p.22

初始的五個位置

位置初始功能
設定 1影像控制
設定 2對焦
設定 3測光方式
設定 4檔案格式
設定 5長寬比

說明書 p.22、p.132

怎麼改

MENU → D2 操作自定義 → ADJ 模式設定 → 設定 1～5

可指定的功能(官方清單)說明書 p.132:關閉、對焦設定、對焦限制器、快拍對焦距離、檔案格式、長寬比、裁切、JPEG 解析度、測光方式、感光度設定、閃光燈模式、閃光量、驅動、自拍、白平衡、影像控制、M 模式單鍵 AE、觸摸 AF、室外顯示設定、幀速率。

街拍向的建議配置
  1. 快拍對焦距離
  2. 影像控制
  3. 感光度設定
  4. 測光方式
  5. 對焦設定

本站建議

ADJ 模式設定只在靜止影像模式有效。影片模式下已固定保存影像控制、對焦、測光方式、幀速率、室外顯示設定,無法更改 說明書 p.133。

開機時與轉動模式轉盤時,螢幕會顯示按鈕目前的功能 3 秒。不想看的話 MENU → E2 顯示設定 → 導標說明 → 關閉 說明書 p.21、p.136。

第三層:USER 模式(整套設定一次切換)

模式轉盤上的 USER1 / USER2 / USER3,可以存下整組拍攝設定,轉過去就全部套用。

能存什麼

  • 曝光模式
  • 曝光補償
  • A 選單與 D 選單的設定(部份設定除外)

說明書 p.127

做法一:直接存目前設定

  1. 先把相機調成你要的樣子(曝光模式與所有功能)。
  2. MENU → D1 USER 模式 → 指定 USER 模式轉盤
  3. 選 USER1 ～ USER3,按 OK。
  4. 選擇是否輸入名稱。要輸入的話最多 32 個半形英數與符號;不輸入就顯示存檔當下的日期時間。
  5. 確認內容,按 OK。

說明書 p.127–128

做法二:用「設定盒 BOX」

除了轉盤上的三格,還可以在 BOX 裡另外保存 6 種設定 說明書 p.129。

  1. 調好設定後 MENU → D1 USER 模式 → 保存 USER 模式 BOX
  2. 選 BOX1 ～ BOX6,可輸入名稱。
  3. 要用時:MENU → D1 USER 模式 → 載入 USER 模式 BOX,選 BOX,再選要指定到轉盤的哪一格。

說明書 p.129–130

USER 模式的兩個重要行為
  • 在 USER 模式下臨時改的設定不會被保存。一切換轉盤就回復成原本存的設定。想改要重新執行保存。
  • 如果你更改了「指定到轉盤的那個 BOX」的內容,轉盤上的設定也會跟著改變。

說明書 p.131

另外還有「重新命名 USER 模式」與「清除 USER 模式指定」可用 說明書 p.128。

全部設錯了想重來

MENU → E11 重設 → 重設設定 / 重設至出廠預設值

「重設至出廠預設值」會把所有功能重設,而且刪除內部記憶體中的影像 說明書 p.24。想只重設部分選單,選「重設設定」,再用「重設項目」逐類開關。

練習 14
  1. 設好 ADJ 的五個位置。
  2. 把 Fn 按鈕指定成「切換快拍」,試著一邊走一邊切換。
  3. 建立 USER1 與 USER2,一天只用 USER1,隔天只用 USER2。強迫自己在限制下拍。
