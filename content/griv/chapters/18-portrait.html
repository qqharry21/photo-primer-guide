人像客製化:對焦模式・USER 設定・快捷鍵

一組打底的人像設定,存進 USER 或 BOX,之後只靠光圈、最低快門速度跟曝光補償三個小地方微調。

這一章不產生新的事實,是把第 07(測光)、第 10(對焦)、第 16(客製化)章已標註出處的內容,重新組成一份人像專用配置。數值建議的部分(光圈、快門、ISO 上限)是本站建議,不是官方規格,標成 本站建議。

對焦怎麼選:「對焦」是 9 選 1,不是兩層設定

容易搞混的地方:「對焦」本身就是一個 9 選一的設定(自動區域 AF / 範圍選擇 AF / 選擇 AF / 精確 AF / 追蹤 AF / 連續 AF / 手動對焦 / 快拍 / ∞,完整說明見第 10 章 對焦:讓它清楚),不是「先選連續或單次、再選對焦點」這種兩層結構。臉部/眼部偵測是另外一個獨立開關,疊加在其中幾個選項之上。

情境「對焦」選哪個臉部/眼部偵測
靜態擺拍(單人特寫,人不太動)精確 AF開啟
一般站姿、微幅走動選擇 AF開啟
小孩、寵物、會亂跑的主體追蹤 AF不支援,先手動框住主體
主體朝你走來或退開(構圖不變)連續 AF不支援

本站建議

臉部/眼部偵測不是每個對焦選項都能用

官方明確寫:設為「自動區域 AF / 範圍選擇 AF / 選擇 AF / 精確 AF」時,相機才能自動偵測人臉、眼睛後對焦 說明書 p.60。追蹤 AF、連續 AF、手動對焦、快拍、∞ 都不支援——所以拍會動的小孩用追蹤 AF 時,眼睛沒有自動優先,得自己先框住人再按下去追。

MENU → A1 對焦設定 → 對焦 / 臉部・眼部偵測

共通基礎設定:存進 USER 前的骨架

核心邏輯:用光圈優先 + Auto ISO 讓相機自己吸收室內外光線差異,你只顧光圈和必要時的曝光補償,不用每次進場配一輪參數。

本站建議 這是起點,不是標準答案,拍兩週後照習慣改。

只需要調的 3 個變因

因為 Auto ISO 已經吸收大部分室內外落差,實際拍的時候只需要看情況動這三個:

情境光圈最低快門速度感光度 AUTO 上限備註
室內・光線充足F2.8–3.51/1251600標準情況
室內・光線不足F2.81/60–1/1003200–6400靜態站姿夠用;對象會動寧可推高 ISO 也別再降快門
室外・光線充足F4–5.61/250200–400順光死白/逆光過曝時曝光補償 −0.3～−0.7
室外・光線不足F2.8–3.21/125–1/160800–1600陰天、黃昏、夜間

本站建議 規律很簡單:光線不足 → 光圈開到底、快門降;室外 → 快門拉高防止過曝,光圈可以縮一點。

存進 USER(或 BOX)

調好上面這些之後,照第 16 章 客製化:ADJ・Fn・USER的步驟存成整組設定。

跟第 16 章的「三套建議配置」對照一下

如果你已經照第 16 章把 USER1／USER2／USER3 存成街拍/黑白/夜間三組,轉盤上沒有空位了——這時候把人像設定存進 BOX(BOX1～6 選一個),要用時 MENU → D1 USER 模式 → 載入 USER 模式 BOX,再選擇要暫時套用到轉盤上的哪一格 說明書 p.129–130。不用為了人像放棄原本三組常用設定。

快捷鍵配置

存好整組之後,搭配以下快捷鍵可以不用進選單就微調:

ADJ 模式的 5 個位置

MENU → D2 操作自定義 → ADJ 模式設定
位置功能
設定 1對焦設定
設定 2測光方式
設定 3感光度設定
設定 4白平衡
設定 5影像控制

本站建議,五項皆為官方可指定給 ADJ 模式的功能說明書 p.132。

Fn 按鈕

MENU → D2 操作自定義 → Fn 按鈕設定 → Fn 按鈕 → 切換追蹤 AF

按一下就能在你設定好的對焦模式(選擇 AF / 精確 AF)跟追蹤 AF 之間切換說明書 p.134——小孩突然亂跑時不用進選單現找。本站建議

四向鍵的上/下/左/右(微距/白平衡/感光度/驅動模式)維持原廠預設就好,人像用得上,不需要另外改說明書 p.20。

完整設定順序

  1. 拍攝模式轉到 Av,光圈設 F4。
  2. MENU → A2 曝光設定 → 感光度設定:AUTO 上限設 6400、最低快門速度設 1/125。
  3. MENU → A2 曝光設定 → 測光方式:選 多區。
  4. MENU → A1 對焦設定 → 對焦:選 選擇 AF;臉部・眼部偵測 設 開啟;完全按下快拍 設 關閉。
  5. 下鍵切 Auto WB;MENU → A5 影像加工設定 → 影像控制 選 正片。
  6. 曝光補償鍵歸零。
  7. MENU → D1 USER 模式 → 指定 USER 模式轉盤(或先存 BOX),存成一組。
  8. MENU → D2 操作自定義 → ADJ 模式設定 / Fn 按鈕設定,照上面兩張表配置快捷鍵。
  9. 出門後只依「只需要調的 3 個變因」表微調光圈/最低快門速度/ISO 上限。
練習
  1. 把對焦分成兩組練習:靜態拍攝全用精確 AF,遇到會動的主體切追蹤 AF,同一組人像各拍一輪比較合焦率。
  2. 存成 USER 或 BOX,兩週內固定用它拍完整組人像,再回頭調整光圈與最低快門速度的基準值。
  3. 把 Fn 按鈕設成切換追蹤 AF,實際測試從「選擇 AF」切到「追蹤 AF」需要多久。
