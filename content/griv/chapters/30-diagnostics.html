互動診斷:現在該調什麼

回答一到兩個問題,直接告訴你調哪個參數、調到多少、在哪個選單。

這一章不提供新的事實,只把第 05～13、20、21、25 章已經標註出處的內容重新排成互動流程。每張答案卡的頁碼都沿用原章節的標註。想知道「為什麼」,每張卡片下方都有連到原章節的連結。

A. 從問題反推設定

你現在的狀況是
照片哪裡不對
放大照片看,是哪一種糊
更精確一點是
顏色是怎麼個怪法
哪一種髒
是哪個狀況
現在的光線與場合是

整張都糊 = 手震,快門太慢

診斷
快門速度慢到擋不住你手持的晃動,所以整個畫面一起位移。
立刻做
最低快門速度提高到 1/250 秒(預設只有 1/30,拍走動的人一定糊);確認 Shake Reduction 開啟 說明書 p.96;手肘夾緊靠身體。
選單路徑
MENU → A2 曝光設定 → 感光度設定 → 最低快門速度
想懂為什麼

只有會動的糊 = 快門不夠快

診斷
背景清楚代表相機沒晃,是主體自己在動的時間被記錄下來了。
立刻做
最低快門速度改 1/250 ～ 1/500 秒。防手震對這種糊完全沒用——它只能修正相機的晃動,修不了被拍的人在走路。
選單路徑
MENU → A2 曝光設定 → 感光度設定 → 最低快門速度
想懂為什麼

主體糊、後面清楚 = 對焦對到後面去了

診斷
相機自己挑的對焦點不是你想要的那個。
立刻做
改用選擇 AF 自己指定對焦點 說明書 p.61;如果你在用快拍,檢查快拍對焦距離是不是設太遠。
選單路徑
MENU → A1 對焦設定 → 自動對焦區域
想懂為什麼

用了快拍卻糊 = 人不在快拍距離的範圍內

診斷
快拍是「先把焦點固定在某個距離」,人站在那個範圍外就是糊的。
立刻做
把光圈縮到 F8 讓景深變深,範圍就變寬;或直接改快拍對焦距離去配合你實際站的位置。
選單路徑
MENU → A1 對焦設定 → 快拍對焦距離
想懂為什麼

近拍怎麼拍都糊 = 這麼近時景深極淺

診斷
微距距離下,清楚的範圍可能只有幾公釐,一點點前後移動就跑掉。
立刻做
光圈縮到 F5.6 ～ F8,並改用精確 AF 對準你要的那一點 說明書 p.58。開啟 Shake Reduction,近距離會放大手震。
選單路徑
MENU → A1 對焦設定 → 自動對焦區域 → 精確 AF
想懂為什麼

白色拍成灰的 = 測光被騙了

診斷
相機測光的預設假設是「畫面平均起來該是中灰色」,所以看到整片白就以為太亮,自動拍暗。這不是故障。
立刻做
曝光補償 +0.7 ～ +1EV。拍完看直方圖再微調。
選單路徑
按機背曝光補償鍵,轉電子轉盤 說明書 p.51
想懂為什麼

夜景像白天 = 測光被騙了(反方向)

診斷
整片暗的畫面,相機以為曝光不足,於是把它拉亮成中灰——夜色的氣氛就沒了。
立刻做
曝光補償 −0.7 ～ −1.3EV。夜景本來就該是暗的。
選單路徑
按機背曝光補償鍵,轉電子轉盤 說明書 p.51
想懂為什麼

天空死白 = 亮部過曝

診斷
亮部一旦白掉,那塊就沒有資料了,事後救不回來。
立刻做
測光方式改高亮重點 說明書 p.65;開啟高亮校正 p.95;打開白點警告,拍之前就會看到哪裡要白掉 p.139。
選單路徑
MENU → A2 曝光設定 → 測光方式 → 高亮重點
想懂為什麼

逆光人臉全黑 = 測光被亮背景拉走

診斷
相機測的是整個畫面,背後的強光把平均值拉高,臉就被壓暗了。
立刻做
曝光補償 +1EV;或把測光方式改成中央重點或重點,只讀臉那一塊的亮度。
選單路徑
MENU → A2 曝光設定 → 測光方式
想懂為什麼

大太陽下過曝 = 撞到快門上限

診斷
F2.8 時快門最快只到 1/2500 官方規格。光再多,相機也沒有更快的門可以關了。
立刻做
光圈縮到 F5.6 以上,或開啟 ND 濾光鏡 直接把進光量壓下來 說明書 p.91。
選單路徑
MENU → A3 拍攝設定 → ND 濾光鏡
想懂為什麼

暗部死黑 = 動態範圍不夠

診斷
同一個畫面裡最亮與最暗差太多,感光元件一次吃不下。
立刻做
開啟陰影校正 說明書 p.95(設為「強」時雜點可能較明顯);或改拍 RAW,之後在電腦上把暗部拉回來。
選單路徑
MENU → A5 影像加工設定 → 動態範圍校正 → 陰影校正
想懂為什麼

室內偏黃 = 鎢絲燈色溫

診斷
黃燈的顏色本來就偏橘,自動白平衡沒有完全修正掉。
立刻做
想校正成白 → 白平衡改鎢絲燈。想保留那份暖 → 用自動白平衡(暖色優先) 說明書 p.73。這是氣氛取捨,沒有標準答案。
選單路徑
按下鍵(白平衡) → 選設定 → OK
想懂為什麼

整體偏藍 = 在陰影或陰天下拍

診斷
陰影處的光其實來自藍色的天空,不是太陽直射。
立刻做
白平衡改陰影或陰天。「陰天」也可以單純拿來讓照片偏暖。
選單路徑
按下鍵(白平衡) → 陰影 / 陰天 → OK
想懂為什麼

夕陽不夠紅 = 白平衡把色偏「修正」掉了

診斷
自動白平衡的工作就是讓白色回到白色——它把夕陽的橘紅當成需要修正的色偏。
立刻做
改用 CTE。它是 Ricoh 特有的,作用是強調色偏而不是修正,會讓紅的更紅 說明書 p.74。
選單路徑
按下鍵(白平衡) → CTE → OK
想懂為什麼

顏色時好時壞 = 自動白平衡每張判斷不同

診斷
同一個場合走幾步,畫面裡的顏色比例變了,自動白平衡就給出不一樣的答案。
立刻做
固定用一種白平衡(依現場光源選日光/鎢絲燈等),整組照片的調性就會一致;或拍 RAW 之後統一套同一組數值。
選單路徑
按下鍵(白平衡) → 選一個固定值 → OK
想懂為什麼

設了黑白卻是彩色 = 影像控制不套用在 RAW 上

診斷
官方明確寫:「影像控制中的設定不適用於 RAW 影像」說明書 p.94。用 RAW+JPEG 拍時,效果只反映在 JPEG 上 p.89。
立刻做
看 JPEG 那個檔就對了;真的想在 RAW 上套用,用機內的 RAW 處理 補上色調 說明書 p.109。
選單路徑
播放 → 選一張 RAW → RAW 處理
想懂為什麼

顆粒多、暗部有雜色 = ISO 太高

診斷
ISO 是把訊號放大,背景的雜訊會一起被放大。官方也寫了:「使用高感光度拍攝的影像可能出現雜點」p.67。
立刻做
把感光度 AUTO 上限降下來(街拍建議 6400);或加大光圈到 F2.8 讓相機不必拉 ISO。
選單路徑
MENU → A2 曝光設定 → 感光度設定 → 感光度 AUTO 上限
想懂為什麼

細節像塑膠 = 雜點抑制開太強

診斷
降噪是把雜點抹掉,抹過頭連真正的細節(頭髮、布料紋理)也一起抹平。
立刻做
高感光度 NR 調低或設成「自動」 說明書 p.71。這是取捨,不是越強越好。
選單路徑
MENU → A5 影像加工設定 → 去除雜點 → 高感光度 NR
想懂為什麼

不夠銳利但沒糊 = 光圈縮太小產生繞射

診斷
光圈縮到很小時,光線通過小孔會擴散,整體銳利度反而下降。攝影通識
立刻做
不要一直用 F16,改用 F5.6 ～ F8。這一段通常是鏡頭最銳利的區間。
選單路徑
Av 模式下轉前電子轉盤改光圈
想懂為什麼

四角比中間暗 = 鏡頭特性

診斷
周邊光量下降是廣角鏡頭的物理特性,不是故障。
立刻做
開啟周邊光量校正 說明書 p.94。(有些人反而喜歡這個效果,覺得畫面更集中——不修也完全可以。)
選單路徑
MENU → A5 影像加工設定 → 周邊光量校正
想懂為什麼

格紋出現彩色波紋 = 摩爾紋

診斷
被攝物的細密紋路與感光元件的畫素排列打架,產生假的彩色條紋。
立刻做
開啟低通濾光鏡模擬器(強/弱)說明書 p.91;已經拍下來的可以用色彩摩爾紋校正補救 p.117。注意:高速快門與閃光燈拍攝時可能無法獲得充分效果 p.91。
選單路徑
MENU → A3 拍攝設定 → 低通濾光鏡模擬器
想懂為什麼

主體太小 = 你站太遠了

診斷
GR IV 是 28mm 定焦,不能變焦。官方規格
立刻做
走近。這是唯一解,沒有第二個辦法。事後裁切會損失畫素。
選單路徑
用腳,不用選單。
想懂為什麼

畫面很亂 = 元素太多,沒有主角

診斷
28mm 視野很大,很容易把不想要的東西一起拍進來。
立刻做
減少畫面中的元素;換個角度讓背景單純(蹲低拍天空、找一面素牆);再靠近一點。按快門前掃一次畫面四角。
選單路徑
打開格線當構圖輔助:MENU → D3 顯示自定義 → 拍攝資訊顯示設定 → 格線
想懂為什麼

照片老是歪的

診斷
手持時很難靠感覺抓水平,尤其畫面裡沒有明顯的水平線時。
立刻做
打開電子水平儀 說明書 p.139;再開自動水平補正,相機會自動修(SR 開啟時最大 1.0 度,SR 關閉時最大 1.5 度)p.96。
選單路徑
MENU → A6 拍攝輔助 → 自動水平補正 → 開啟
想懂為什麼

人臉被拉長 = 廣角邊緣變形

診斷
廣角鏡頭在畫面邊緣一定會有拉伸,越靠角落越明顯。這是光學特性。攝影通識
立刻做
把人往畫面中間放。這是構圖問題,沒有選單可以修。
選單路徑
重新構圖,不用選單。
想懂為什麼

白天街拍:起手設定

立刻做
曝光模式 Av 光圈優先 / 光圈 F8 / 對焦快拍 2.5m / 完全按下快拍開啟 / ISO AUTO 上限 6400 / 最低快門速度 1/250 / 測光多區 / 影像控制正片。
為什麼
F8 的景深夠深,配上快拍就是「舉起來就拍到」,零對焦延遲。1/250 讓走動的路人不會糊。
出處
本站建議 這是起始值,不是官方規定。選項名稱與位置依官方說明書。
完整版

夜間 / 低光:起手設定

立刻做
光圈 F2.8 / 對焦選擇 AF(暗處快拍容易失手)/ ISO AUTO 上限 12800～25600 / 最低快門速度 1/60 / 測光高亮重點 / 曝光補償 −0.7 ～ −1.3EV / Shake Reduction 開啟。
為什麼
高亮重點讓霓虹燈不會白掉;負補償保住夜的氣氛。找牆壁、欄杆、地面靠著拍,比任何防手震都有效。
出處
本站建議 起始值。測光方式依 說明書 p.65。
完整版

室內 / 陰天:起手設定

立刻做
光圈 F2.8 ～ F4 / ISO AUTO 上限 6400 / 最低快門速度 靜物 1/60、有人在動 1/250 / 白平衡自動白平衡(暖色優先) / 測光多區。
為什麼
暖色優先會保留室內燈光的暖調,不會把氣氛校正掉 說明書 p.73。
出處
本站建議 起始值。
完整版

微距 / 食物與小東西:起手設定

立刻做
微距模式開啟(按上鍵,對焦 6～15cm)/ 光圈 F5.6 ～ F8 / 對焦精確 AF / Shake Reduction 開啟。
為什麼
這麼近時景深極淺,要縮光圈換深度。近距離也會放大手震。
注意
微距模式下無法使用完全按下快拍 說明書 p.64。
完整版

長曝光(車軌、流水):起手設定

立刻做
三腳架必備 / 曝光模式 M 手動 / ISO 固定 100(才能用 B/T/BT)/ 光圈 F8 ～ F16 / 快門用 T 或 BT / 自拍 2 秒(避免按快門的震動)/ 低速快門 NR 自動或開啟。
白天太亮時
開啟 ND 濾光鏡 說明書 p.91,否則長曝一定過曝。
出處
本站建議 起始值。
完整版

B. 從想要的感覺挑濾鏡

GR IV 的「影像控制」就是機內濾鏡,選好之後拍出來的 JPEG 直接是那個味道,不用後製 說明書 p.92。下面不從 14 個名字裡挑,而是從你想要的感覺反查。

你想要什麼感覺

真實乾淨 → 標準

官方說明
標準畫質 說明書 p.92
建議參數
不動。這是基準點,先用它拍一陣子,你才知道其他色調到底改了什麼。本站建議
適合
要記錄、要後製、或不確定的時候。
選單路徑
MENU → A5 影像加工設定 → 影像控制 → 標準

濃郁鮮豔 → 正片(或鮮艷)

官方說明
正片:拍攝如使用正片拍攝的高飽和度影像。鮮艷:拍攝清晰醒目、色調鮮明的影像 說明書 p.92
建議參數
先用正片不動參數。想再重一點,按 Fn 進去把對比度 +1。本站建議
適合
晴天、藍天、風景、招牌顏色多的街景。這是 GR 的招牌色。
選單路徑
MENU → A5 影像加工設定 → 影像控制 → 正片

日系淡雅 → 底片

官方說明
拍攝如使用底片拍攝的影像 說明書 p.92
建議參數
按 Fn 進去把飽和度 −1、對比度 −1,想要顆粒感再把粒紋感 +1。本站建議
適合
陰天、室內、生活隨拍。光線很硬的大晴天用這個會顯得灰。
選單路徑
MENU → A5 影像加工設定 → 影像控制 → 底片

黑白硬派 → 高對比度黑白

官方說明
拍攝突出對比度的黑白影像。拍攝具有粗糙感的影像,如在膠片照相機中使用超感光度膠片 說明書 p.92
建議參數
按 Fn 進去把粒紋感 +2。黑白專用的濾光鏡效果可以讓天空變深,值得試。本站建議
適合
街拍、強烈光影、陰影很重的場景。這是 GR 最有名的黑白。
選單路徑
MENU → A5 影像加工設定 → 影像控制 → 高對比度黑白

黑白柔和 → 軟單色

官方說明
拍攝給人柔和印象的黑白影像(影片模式無法選)說明書 p.92
建議參數
不動。想更硬一點就改用硬單色(給人硬朗印象),想最中性就用單色。本站建議
適合
人像、靜物、光線柔和的室內。
選單路徑
MENU → A5 影像加工設定 → 影像控制 → 軟單色

電影感 → 電影(黃色) / 電影(綠色)

官方說明
電影(黃色):拍攝帶黃色調的電影感影像。電影(綠色):拍攝陰影側帶綠色調的電影感影像 說明書 p.92
建議參數
兩個都拍一張再決定——黃色版偏暖偏懷舊,綠色版偏冷偏疏離,差異在陰影裡最明顯。本站建議
適合
夜晚街景、有燈光的室內、想要敘事感的畫面。
選單路徑
MENU → A5 影像加工設定 → 影像控制 → 電影(黃色)

舊照片 → 懷舊

官方說明
拍攝仿若舊照片的影像 說明書 p.92
建議參數
不動就很到位。想更舊可以加粒紋感。本站建議
適合
老街、舊建築、家庭紀錄。
選單路徑
MENU → A5 影像加工設定 → 影像控制 → 懷舊

想玩點怪的 → 正負逆沖 / 跳漂白

官方說明
正負逆沖:更改色彩及對比度,拍攝如進行了交叉沖印的影像。跳漂白:拍攝降低飽和度、突出對比度的影像 說明書 p.92
建議參數
這兩個個性很強,不建議當日常設定。挑特定場景玩就好。本站建議

選任何色調之前先記住這一條

官方明確寫:「影像控制中的設定不適用於 RAW 影像」說明書 p.94。用 RAW+JPEG 拍時,效果只反映在 JPEG 上 p.89。所以你設了黑白,電腦打開 RAW 還是彩色的——這是正常的。

本站建議 選項太多反而不會拍。新手先固定用兩個就好:彩色用正片,黑白用高對比度黑白。等你看膩了再回來試其他 12 種。調出喜歡的參數後,存成自定義 1～3 就不用每次重設 說明書 p.92–93。

練習
  1. 翻出你最近拍壞的 5 張,每一張都用上面的 A 模組跑一次,把答案卡指的那個參數記下來。
  2. 找出重複出現最多次的那個參數——那就是你現在最該改的設定。改掉它。
  3. 用 B 模組挑一個你從沒用過的色調,帶著它出門拍一整天,只用那一個。
