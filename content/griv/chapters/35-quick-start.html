速讀:沒時間全看,先讀這幾章

這個分頁章節很多,不必全部讀完才出門。這一頁告訴你最少讀哪幾章、現場遇到逆光或太暗怎麼救,以及哪些機身設定能幫你構圖。

重點摘要
  • 最短路線只有 5 章:曝光補償與測光、決策地圖、快拍、客製化、情境速查;其他章節遇到問題再查。
  • 逆光臉黑先 +1EV 或換中央重點測光;天空白掉改高亮重點測光;暗部死黑開陰影校正。
  • 太暗照抄這組:F2.8、ISO AUTO 上限 12800～25600、最低快門 1/60、Shake Reduction 開、找東西靠。
  • 構圖輔助把格線、電子水平儀、白點警告、直方圖全部打開,再開自動水平補正;Fn 鍵指定「裁切」可以一鍵換 35/50mm 視角。
  • USER1～3 直接照抄客製化那一章的街拍/黑白/夜間三組,轉一下轉盤就換好整套設定。
還不熟曝光三角和構圖?

先讀白話總複習:曝光三角與構圖,它用最白話的方式把兩件事講完。這一頁只講 GR IV 上實際要按哪裡。

最短閱讀路線:5 章就能上手

本站建議 照順序讀,一次一章,讀完就出門試:

順序章節讀完會什麼
1曝光補償・測光・直方圖照片太亮太暗會自己修,知道逆光該換哪種測光
2該調哪一個?決策地圖遇到糊掉、背景不夠糊、太暗時,知道該動光圈、快門還是 ISO
3快拍 Snap:GR 的靈魂不用等對焦,舉起來就拍,專心看構圖
4客製化:ADJ・Fn・USER把常用設定放到按鍵和轉盤上,不用進選單
5情境速查:照抄就能拍街拍、夜間、室內、微距各有一組照抄就能用的數值
拍壞了再查這兩章

不用先讀,拍出問題時再翻:拍壞了?診斷表(看症狀找解法)和互動診斷:現在該調什麼(點選症狀直接給答案)。

現場急救一:逆光

你看到的立刻做出處
人臉黑、背景正常曝光補償 +1EV;或測光改中央重點、重點,只讀臉那一塊決策地圖
天空整片白掉測光改高亮重點 說明書 p.65;開高亮校正 p.95;開白點警告先看到哪裡要白 p.139診斷表
暗部一片黑沒細節開陰影校正(設「強」時雜點可能較明顯)說明書 p.95;或改拍 RAW 事後再拉ISO 感光度

測光方式在 MENU → A2 曝光設定 → 測光方式;高亮校正、陰影校正在 MENU → A5 影像加工設定 → 動態範圍校正 說明書 p.65、p.95。注意高亮校正在感光度低於 ISO 200 時不會啟動 p.95。

逆光不要硬拉三角

臉黑但背景正常,是相機被亮背景騙了,不是光不夠。這時候去開大光圈或拉 ISO,整張都會變亮,天空直接白掉 本站建議。

現場急救二:太暗(室內、晚上)

照抄這組起始值,拍幾張再依畫面微調 本站建議:

設定值白話為什麼
曝光模式光圈優先(Av)你只管光圈,其他相機補
光圈F2.8開到最大,盡量多收光
對焦選擇 AF暗處快拍容易失手,改回精準對焦
感光度AUTO,上限 12800～25600光不夠只能靠 ISO,接受顆粒
最低快門速度1/60比白天放寬一點換亮度
測光方式高亮重點霓虹燈、路燈不會白掉
曝光補償−0.7 ～ −1.3EV不要把夜晚拍成白天
Shake Reduction開啟低光防手震

找牆壁、欄杆、桌面靠著拍,比任何防手震設定都有效。完整說明見情境速查的「夜間 / 低光」。

現場急救三:拍會動的東西、邊走邊拍

GR IV 沒有雲台,「動」的問題靠快門和快拍解決 本站建議:

狀況設定
路人走動、邊走邊拍最低快門速度 1/250(1/125 較冒險,1/500 最保險)
來不及對焦快拍 2.5m + 光圈 F8,景深夠深不用等對焦
想一按到底就拍開啟完全按下快拍:半按=慢慢對焦,一按到底=搶拍
拍糊了先調快門,不要去開光圈或拉 ISO——那樣只是更亮,還是糊

細節見快拍 Snap與街拍實戰。

構圖輔助:讓相機幫你擺正、找位置

這幾個設定打開後就不用再管,新手建議全部開著 本站建議:

設定幫你做什麼在哪裡
格線(9 網格 / 16 網格)螢幕上畫九宮格,主角直接放在交叉點D3 → 拍攝資訊顯示設定 → 格線;樣式在 D3 → 格線種類 說明書 p.34、p.139
電子水平儀顯示相機有沒有歪,地平線對齊用D3 → 拍攝資訊顯示設定 p.139
自動水平補正拍歪一點點時自動修正:SR 開啟最多 1.0 度、SR 關閉最多 1.5 度A6 拍攝輔助 → 自動水平補正 p.96
白點警告會過曝的地方紅色閃爍,拍之前就知道天空會不會白D3 → 拍攝資訊顯示設定 p.139
直方圖亮度成績單,不用靠螢幕亮度猜D3 → 拍攝資訊顯示設定 p.139
觸摸 AF多人時直接點要對焦的那張臉D2 → 觸摸 AF p.60

兩個幫你「換視角」的設定

設定怎麼幫構圖
裁切(35mm / 50mm)站著不動就能換成比較窄的視角,適合拍人像、拿掉邊緣雜物。這是數位裁切,JPEG 畫素會變少 說明書 p.90。建議配 RAW+JPEG:得到裁好的 JPEG,也保留完整 28mm 的 RAW,隨時反悔 本站建議
長寬比 1:1強迫自己用正方形構圖一整天,練「只留主角」的眼光。RAW 仍以完整 26M 記錄 說明書 p.89
28mm 的三個提醒

覺得主角太小 → 走近,不能變焦;人臉不要放畫面邊緣,會被拉長;按快門前掃一次四個角,視野很寬容易拍進雜物。細節見構圖與光線。

按鍵與 USER 推薦:一次設好,之後不用想

設定方法見客製化:ADJ・Fn・USER,這裡只給結論 本站建議:

位置建議指定為什麼
Fn 按鈕切換快拍一鍵在快拍與 AF 之間切,街拍最常用
其中一顆可自訂鍵裁切一鍵換 35 / 50mm 視角,構圖不夠緊時用
ADJ 五個位置快拍對焦距離、影像控制、感光度、測光方式、對焦設定逆光要換測光、夜間要改 ISO,按一下轉盤就改得到
USER1街拍:F8、快拍 2.5m、最低快門 1/250、多區測光白天出門的主力
USER2黑白:F5.6、快拍 2m、高對比度黑白換心情、練光影
USER3夜間:F2.8、選擇 AF、ISO 上限 25600、最低快門 1/60、高亮重點、−0.7EV天一黑轉過去就好

USER 模式下臨時改的設定不會被保存,轉一下轉盤就回到原本存的值 說明書 p.131——所以放心亂調,不會弄壞你存好的那組。三組完整數值見客製化的「三套建議配置」。

行動建議
  1. 今天就把格線、電子水平儀、白點警告、直方圖四個打開,再開自動水平補正。
  2. 照上面那張表設好 Fn 和 USER1～3,白天用 USER1 出門拍一次,晚上轉到 USER3 再拍一次。
  3. 刻意找一個逆光場景,依序試 +1EV、中央重點測光、高亮重點測光,記住哪一招最適合你常拍的東西。
  4. 照最短路線讀完 5 章,每讀一章就出門試那一章的練習,再讀下一章。
